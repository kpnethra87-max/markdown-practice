# Code of Conduct

## Our Pledge

We aim to create a friendly, respectful, and welcoming environment for everyone.

## Expected Behaviour

- Be respectful to everyone.
- Accept feedback politely.
- Respect different opinions.
- Help others learn and improve.

## Unacceptable Behaviour

- Harassment or discrimination.
- Offensive comments.
- Personal attacks.

## Reporting

If you notice any unacceptable behaviour, contact the repository owner through their GitHub profile.

All concerns should be handled respectfully.
